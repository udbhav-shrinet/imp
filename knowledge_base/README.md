# Knowledge Base

The authoritative specification for the current hierarchy is
[`hierarchical_bulk_trading.md`](./hierarchical_bulk_trading.md). It documents
the formulas, thresholds, candle topics, model features, allocation rules and
operating constraints implemented by the code.

The project uses short in-repository explanations rather than bundling
copyrighted books. Recommended study topics are market microstructure,
technical analysis, time-series statistics, probability calibration,
walk-forward validation, portfolio construction, volatility targeting and
order execution.
